# Zombie AI Neuroevolution Simulation - English Documentation

This project is a 3D multi-level Zombie AI survival simulation featuring neuroevolution (GRU recurrent neural networks with PyTorch), dynamic chunk-based world generation, realistic city zoning, and Lua modding capabilities.
