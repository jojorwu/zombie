# Обзор архитектуры

## Структура проекта
- `src/world.py`: Основные классы `World`, `ChunkManager`, типы тайлов, модификаторы скорости передвижения и генераторы городских районов.
- `src/brain.py`: Рекуррентная нейросеть `BrainNet` на PyTorch (GRU), функции пакетного инференса (batched inference) и менеджер эволюции `GeneticEvolutionManager`.
- `src/entities.py`: Игровые сущности (`Survivor`, `Zombie`, `Animal`, `Vehicle`, `ItemEntity`), а также акустическое распространение шума.
- `src/pathfinding.py`: Навигация 3D A* с поддержкой лестниц, ступеней и штрафов за тип поверхности.
- `src/simulation.py`: Игровой движок `SimulationEngine`, симуляционный цикл и сброс поколений.
- `src/ui.py`: Пользовательский интерфейс Pygame, главное меню, настройки и камеры.
- `src/modding.py`: Движок модификаций на Lua с использованием библиотеки `lupa`.
