# Руководство по модингу на Lua

Моды находятся в папке `mods/` и загружаются через `src/modding.py`.

## Доступные колбэки
- `on_init()`: Вызывается при инициализации мода.
- `on_tick(tick)`: Вызывается на каждом тике симуляции.
- `on_survivor_action(survivor_id, action)`: Вызывается, когда выживший совершает действие.

## Функции API
- `log(message)`: Печать сообщения в консоль.
- `add_item_type(id, name, type)`: Регистрация новых предметов.
