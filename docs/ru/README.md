# Симуляция ИИ Выживания и Нейроэволюции - Документация на русском

Данный проект представляет собой 3D многоуровневую симуляцию выживания зомби с нейроэволюцией (рекуррентные нейросети GRU на PyTorch), динамической генерацией мира на основе чанков, реалистичным зонированием города и поддержкой модов на языке Lua.
